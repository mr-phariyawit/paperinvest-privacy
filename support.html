ต้องมีอะไรก่อนใช้ส่วนที่เป็น AI?

ต้องมี Gemini API key ของคุณเอง สร้างได้ที่ Google AI Studio แล้ววางในหน้า “ตั้งค่า key” ของแอป ค่าใช้จ่ายและโควตาเป็นไปตามบัญชี Google ของคุณ แอปไม่เก็บเงินและไม่มีบริการ AI ของตัวเอง

ยังไม่มี key ลองใช้ได้ไหม?

ได้ ที่หน้าตั้งค่า key กด “ข้ามไปก่อน — ใช้ข้อมูลตัวอย่าง” แอปจะใช้โปรเจกต์ตัวอย่าง (บูธเนื้อโคขุน) ทุกขั้น โดยไม่เรียก Gemini ทุกหน้าที่ใช้ข้อมูลตัวอย่างมีป้ายสีส้ม “โหมดตัวอย่าง” ใส่ key เมื่อไรก็ใช้ AI จริงได้

ข้อมูลของฉันอยู่ที่ไหน?

  • โปรเจกต์ (ไอเดีย คำตอบ ตารางต้นทุน สูตร ประวัติ) เก็บในเครื่องของคุณ แอปไม่มีเซิร์ฟเวอร์และไม่มีบัญชีผู้ใช้
  • API key เก็บใน Keychain ของเครื่องนี้เท่านั้น
  • เมื่อใช้ AI ข้อความที่เกี่ยวข้องจะถูกส่งจากเครื่องตรงไปที่ Google ด้วย key ของคุณ ถ้าใช้ key แบบไม่เสียเงิน Google อาจนำข้อความไปปรับปรุงบริการได้ จึงไม่ควรใส่ข้อมูลส่วนตัวหรือความลับธุรกิจ

รายละเอียดทั้งหมดอยู่ในนโยบายความเป็นส่วนตัว

ลบโปรเจกต์ได้อย่างไร?

  • ในหน้ารายการโปรเจกต์ ปัดโปรเจกต์ไปทางซ้ายแล้วกด “ลบ” หรือในหน้าโปรเจกต์กดเมนู (⋯) → “ลบโปรเจกต์…”
  • แอปจะถามยืนยันก่อน ลบแล้วกู้คืนไม่ได้ และ key จะไม่ถูกลบไปด้วย
  • ลบ key: หน้าตั้งค่า key → “ลบ key…” ควรทำก่อนลบแอป เพราะข้อมูลใน Keychain อาจยังอยู่แม้ลบแอปแล้ว

ผลที่แอปคำนวณเชื่อถือได้แค่ไหน?

ผลทั้งหมดเป็นค่าประมาณเพื่อช่วยวางแผน ไม่ใช่คำแนะนำการลงทุน และไม่รับประกันกำไร ตัวเลขจาก AI ผิดได้ แอปจึงติดป้ายทุกตัวเลขว่ามาจากไหน (คุณใส่เอง / AI ประมาณ / AI ค้นเจอ) และมีหน้า “ต้องไปถามอะไร” ให้ไปเช็กกับคนจริงแล้วกลับมาใส่ตัวเลขจริง
