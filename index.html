นโยบายความเป็นส่วนตัว — แอป “คิดก่อนควัก – Paper First”

มีผลตั้งแต่ 27 ตุลาคม 2569 (2026-10-27) · ผู้พัฒนา Phariyawit Chaiparitte

สรุปสั้น ๆ

  • เราไม่มีเซิร์ฟเวอร์ของเราเอง ข้อมูลที่คุณพิมพ์ไม่ได้ถูกส่งมาที่เรา
  • เมื่อแอปใช้ AI ข้อความที่เกี่ยวข้องจะถูกส่งจากเครื่องของคุณตรงไปที่ Google (Gemini API) ด้วย API key ของคุณเอง
  • API key ของคุณเก็บไว้ใน Keychain ของเครื่องนี้เท่านั้น ไม่ sync ไปเครื่องอื่น
  • แอปไม่มีโฆษณา ไม่มีระบบวิเคราะห์การใช้งาน (analytics) และไม่ติดตามคุณข้ามแอปหรือเว็บไซต์

1. ข้อมูลที่เก็บไว้ในเครื่องของคุณ

  • ข้อมูลโปรเจกต์: ไอเดียธุรกิจ คำตอบสัมภาษณ์ ตารางต้นทุน สูตร ประวัติการแก้ไข และรายการที่ต้องไปถาม เก็บในพื้นที่ของแอปบนเครื่องนี้
  • ชื่อที่คุณใส่ (ไม่บังคับ): ใช้บันทึกว่าใครกรอกตัวเลขในตาราง เก็บในการตั้งค่าของแอปบนเครื่องนี้
  • การตั้งค่า: ว่าคุณกดยอมรับข้อตกลงแล้วหรือยัง และประเภท key ที่คุณเลือก (ฟรี / เปิด billing / ไม่แน่ใจ)
  • Gemini API key: เก็บใน iOS Keychain แบบ “เฉพาะเครื่องนี้” ไม่ sync ผ่าน iCloud และไม่ถูกส่งมาที่เรา

2. ข้อมูลที่ถูกส่งไปที่ Google

เมื่อคุณใส่ key แล้วใช้ขั้นตอนที่ใช้ AI (สัมภาษณ์ ทำตารางต้นทุน ค้นราคาจากเว็บ เขียนสูตร) แอปจะส่งข้อความต่อไปนี้ไปที่ Google Gemini API โดยตรงจากเครื่องของคุณ พร้อม key ของคุณ:

  • ไอเดียธุรกิจและคำตอบที่คุณพิมพ์
  • บรรทัดในตารางต้นทุนที่เกี่ยวข้อง
  • คำสั่ง (prompt) ที่แอปเขียนไว้ เพื่อให้ AI ตอบในรูปแบบที่แอปอ่านได้

Google จัดการข้อมูลนี้ตามเงื่อนไขของ Google ที่คุณยอมรับตอนสร้าง key — ไม่ใช่ตามนโยบายนี้ สรุปจากเงื่อนไขฉบับปัจจุบันของ Google:

  • ถ้า key ของคุณใช้แบบไม่เสียเงิน Google นำข้อความที่ส่งไปและคำตอบที่ได้ไปใช้ปรับปรุงและพัฒนาผลิตภัณฑ์ของ Google ได้ และอาจมีคนของ Google อ่านข้อความเหล่านั้น (Google บอกว่าจะตัดออกจากบัญชีและ key ของคุณก่อน)
  • ถ้าเปิด billing แล้ว Google บอกว่าจะไม่นำข้อความไปปรับปรุงผลิตภัณฑ์ แต่เก็บไว้ช่วงสั้น ๆ เพื่อตรวจการใช้งานที่ผิดเงื่อนไขและตามที่กฎหมายกำหนด

รายละเอียดอยู่ใน Gemini API Additional Terms of Service และ Google Privacy Policy แอปจึงเตือนว่า ห้ามใส่ข้อมูลส่วนตัวหรือความลับธุรกิจ

เราในฐานะนักพัฒนาไม่ได้รับข้อความเหล่านี้ แต่เพราะข้อความถูกส่งออกจากเครื่องไปที่ Google เพื่อให้แอปทำงาน ในหน้า App Store เราจึงประกาศว่าแอปเก็บ “เนื้อหาอื่นของผู้ใช้” (Other User Content) ใช้เพื่อให้แอปทำงานเท่านั้น ไม่ผูกกับตัวตนของคุณ และไม่ใช้ติดตาม

ถ้าคุณใช้ “ข้อมูลตัวอย่าง” โดยไม่ใส่ key แอปจะไม่ส่งอะไรไปที่ Google เลย

3. ผลค้นเว็บ

เมื่อ AI ค้นราคาจากเว็บ แอปจะแสดงคำค้นแนะนำและลิงก์ที่มาจาก Google ถ้าคุณกดลิงก์ ระบบจะเปิดหน้าเว็บนั้นนอกแอป และเว็บนั้นใช้นโยบายของตัวเอง

4. PDF ที่คุณส่งออก

แอปสร้าง PDF บนเครื่องเมื่อคุณกดเท่านั้น คุณเป็นผู้เลือกว่าจะแชร์ไปที่ไหน แอปไม่ส่ง PDF ไปที่อื่นเอง

5. สิ่งที่แอปไม่ทำ

  • ไม่มีบัญชีผู้ใช้ ไม่ต้องสมัครหรือล็อกอิน
  • ไม่มีโฆษณา ไม่มี analytics ไม่มี SDK ของบุคคลที่สาม
  • ไม่ติดตาม (tracking) ไม่ขายข้อมูล และไม่ส่งข้อมูลให้ใครนอกจาก Google ตามข้อ 2 เพื่อให้ AI ทำงาน

6. การลบข้อมูล

  • ลบ key: ไปที่หน้าตั้งค่า key แล้วกด “ลบ key…” — แนะนำให้ทำก่อนลบแอป เพราะข้อมูลใน Keychain ของ iOS อาจยังอยู่แม้ลบแอปแล้ว
  • ลบโปรเจกต์: ปัดรายการโปรเจกต์ไปทางซ้ายแล้วกด “ลบ” หรือในหน้าโปรเจกต์กดเมนู (⋯) → “ลบโปรเจกต์…” แอปจะถามยืนยันก่อน เมื่อลบแล้ว ตาราง สูตร ประวัติ รายการที่ต้องไปถาม และไฟล์ของโปรเจกต์นั้นในเครื่อง (เช่นคำค้นแนะนำและ PDF ที่สร้างไว้) จะถูกลบทั้งหมดและกู้คืนไม่ได้ การลบโปรเจกต์ไม่ลบ Gemini key
  • ลบทุกอย่าง: ลบแอปออกจากเครื่อง (และลบ key ในแอปก่อน ตามข้อแรก)
  • ข้อมูลที่เคยส่งไป Google แล้ว เราลบให้ไม่ได้ เพราะไม่ได้ผ่านเรา — ดูวิธีจัดการได้ที่เงื่อนไขของ Google

7. เมื่อแอปเพิ่มการแชร์ (เฟส 2 — ยังไม่มีในรุ่นนี้)

เราวางแผนให้แชร์โปรเจกต์กับคนอื่นผ่าน iCloud ของ Apple เมื่อถึงตอนนั้น ข้อมูลโปรเจกต์จะเก็บใน iCloud ของคุณ (ไม่ใช่เซิร์ฟเวอร์ของเรา) และคนที่คุณเชิญจะเห็นโปรเจกต์ที่แชร์ API key จะยังอยู่เฉพาะเครื่องและไม่ถูกแชร์ เราจะแก้นโยบายนี้ก่อนเปิดใช้ฟีเจอร์นั้น

8. เด็ก

แอปนี้ทำมาสำหรับผู้ใหญ่ที่วางแผนธุรกิจ ไม่ได้ออกแบบมาสำหรับเด็ก

9. การเปลี่ยนแปลงนโยบาย

ถ้าเราแก้นโยบายนี้ เราจะเปลี่ยนวันที่ด้านบนและแจ้งในบันทึกของรุ่นใหม่

English summary

  • We run no server. Nothing you type is sent to us.
  • When the app uses AI, the relevant text (your business idea, your answers, cost-table lines and the app's prompt) is sent directly from your device to Google's Gemini API using your own API key. Google handles it under its own terms (Gemini API terms, Google Privacy Policy); under Google's current terms, with an unpaid key Google may use prompts and responses to improve its products and human reviewers may read them (after Google disconnects them from your account and key); with billing on, Google says it does not use them to improve its products. Do not enter personal data or business secrets. We never receive this text, but because it leaves the device for Google so the app can work, the App Store label declares it as Other User Content, used for App Functionality only, not linked to you, not used for tracking.
  • Your API key is stored in the iOS Keychain on this device only and never syncs.
  • Projects, your optional name and settings are stored on your device. Sample mode (no key) sends nothing to Google.
  • No accounts, no ads, no analytics, no third-party SDKs, no tracking.
  • Delete a project by swiping it left in the list, or from the project page menu; the app asks first, and deletion cannot be undone. It removes the project's table, formula, history, to-do list and its local files; it does not delete the key.
  • Delete the key in the app before deleting the app (Keychain items can survive app deletion). Deleting the app removes all project data.
  • Planned phase 2: sharing through your own iCloud. This policy will be updated before that ships.
